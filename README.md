# Barkha Yadav | Portfolio

Personal portfolio of Barkha Yadav, Interior, Event & Exhibition Designer (2D/3D CAD) based in Bangalore.

Built with React, TypeScript, Vite, Tailwind CSS, Framer Motion and Lenis.

## Sections
Hero, About, Selected Work (exhibition stands, conferences and events, CAD drawings, interiors and decor), Skills, Experience, Contact.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
npm run preview
```

## Editing content
- Text and work galleries: `src/components/*.tsx`
- Work images: `public/work/`
- Resume PDF: `public/resume.pdf`
- Profile photo: `src/assets/portrait.jpg`
